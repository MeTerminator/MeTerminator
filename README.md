# Projects

* [MeetSchedule](https://meetschedule.top/)

    * Meet 课程表用 AI Agent 识别课表截图或教务系统页面，几秒钟导入任意学校的课程安排；支持自定义课程、事件、作业与考试，云端同步到你的每一台设备。
    * MeetSchedule uses an AI Agent to recognize timetable screenshots or academic portal pages and import course schedules from any school in seconds. It supports custom courses, events, assignments, and exams, with cloud sync across all your devices.

* [ClipBox](https://github.com/MeTerminator/ClipBox)

    * 临时文件分享站，支持文件、剪贴板和短链接分享，并集成可配置考试科目与时间、支持 NTP 时间同步的考试时钟。
    * A temporary sharing service for files, clipboard content, and short links, with a configurable examination clock and NTP time synchronization.

* [MeT-Music_UI](https://github.com/MeTerminator/MeT-Music_UI)

    * 基于 AMLL 的 MeT-Music 网页前端，支持逐字歌词、音乐频谱、隔空播放，以及 QQ 音乐与网易云音乐双平台。
    * The MeT-Music web frontend built around AMLL, featuring word-by-word lyrics, audio visualization, remote playback, and support for QQ Music and NetEase Cloud Music.

* [MeT-Music_Desktop](https://github.com/MeTerminator/MeT-Music_Desktop)

    * 基于 Electron 的 MeT-Music 桌面客户端，支持桌面歌词、后台播放与播放控制，可运行于多个平台。
    * An Electron-based MeT-Music desktop client with desktop lyrics, background playback, and playback controls across multiple platforms.

* [MeT-Music_Player](https://github.com/MeTerminator/MeT-Music_Player)

    * 基于 React、TypeScript 和 Vite 的网页播放器，通过 Session ID 同步 MeT-Music 播放，展示歌曲信息、实时歌词、音频频谱与封面背景。
    * A web player built with React, TypeScript, and Vite that synchronizes MeT-Music playback through a Session ID and displays track information, live lyrics, audio visualization, and cover backgrounds.

* [met-home](https://github.com/MeTerminator/met-home)

    * 我的个人主页，基于 Vue 3、TypeScript、Three.js 和 GSAP 构建。
    * My personal homepage, built with Vue 3, TypeScript, Three.js, and GSAP.

* [met-website-proxy](https://github.com/MeTerminator/met-website-proxy)

    * Met6.top 的网站代理项目。
    * The website proxy project for Met6.top.

* [MeT-Music_iOS](https://github.com/MeTerminator/MeT-Music_iOS)

    * 基于 SwiftUI 的 MeT-Music 原生客户端，支持 iPhone、iPad 和 macOS，提供逐字歌词、后台播放、一起听与本地缓存。
    * A native SwiftUI MeT-Music client for iPhone, iPad, and macOS, featuring word-by-word lyrics, background playback, shared listening rooms, and local caching.

* [MeT-Music_Android](https://github.com/MeTerminator/MeT-Music_Android)

    * 基于 Kotlin Multiplatform 和 Compose Multiplatform 的 MeT-Music 播放器，支持 Android、Web 和桌面端，集成 AMLL/TTML 歌词解析与同步显示。
    * A MeT-Music player built with Kotlin Multiplatform and Compose Multiplatform for Android, Web, and desktop, with AMLL/TTML lyric parsing and synchronized display.


* [FancyDeck](https://github.com/MeTerminator/FancyDeck)

    * 插件驱动的桌面信息屏，支持时间、天气、音乐与歌词等卡片，通过触发条件自动切换布局，并提供可视化管理后台。
    * A plugin-driven desktop information display with cards for time, weather, music, and lyrics, automatic layout switching based on triggers, and a visual management console.
