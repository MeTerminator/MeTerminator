## MeT-Music

覆盖网页、桌面与移动端的音乐项目，围绕逐字歌词、跨设备播放与一起听体验构建。
A family of web, desktop, and mobile music projects focused on word-by-word lyrics, cross-device playback, and shared listening.

* [MeT-Music_UI](https://github.com/MeTerminator/MeT-Music_UI)

    * 基于 SPlayer 改造的 MeT-Music 网页前端，集成 AMLL 逐字歌词、音乐频谱与隔空播放；支持 QQ 音乐和网易云音乐，可分别管理双平台账号与歌单。
    * The MeT-Music web frontend adapted from SPlayer, with AMLL word-by-word lyrics, audio visualization, and remote playback. It supports QQ Music and NetEase Cloud Music, with separate accounts and playlists for each platform.

* [MeT-Music_Player](https://github.com/MeTerminator/MeT-Music_Player)

    * 基于 React、TypeScript 和 Vite 的独立网页播放器，通过 Session ID 与 WebSocket 同步 MeT-Music 播放，展示实时歌词、音频频谱与封面背景，支持 QQ 音乐和网易云音乐。
    * A standalone web player built with React, TypeScript, and Vite that synchronizes MeT-Music playback through a Session ID and WebSocket, with live lyrics, audio visualization, cover backgrounds, and support for QQ Music and NetEase Cloud Music.

* [MeT-Music_Desktop](https://github.com/MeTerminator/MeT-Music_Desktop)

    * 基于 Electron 的 Windows、macOS 和 Linux 桌面客户端，提供全屏播放器、可自定义的桌面歌词、托盘后台播放、媒体键与全局快捷键，并支持可选的本地 HTTP / WebSocket 播放控制接口。
    * An Electron client for Windows, macOS, and Linux with a full-screen player, customizable desktop lyrics, tray playback, media keys, and global shortcuts, plus optional local HTTP / WebSocket APIs for playback control.

* [MeT-Music_Android](https://github.com/MeTerminator/MeT-Music_Android)

    * 基于 Kotlin Multiplatform 和 Compose Multiplatform 的播放器，覆盖 Android、Web 与 JVM 桌面端；支持 QQ 音乐和网易云音乐、AMLL/TTML 及 YRC 逐字歌词、一起听与音频缓存。
    * A player built with Kotlin Multiplatform and Compose Multiplatform for Android, Web, and JVM desktop, featuring QQ Music and NetEase Cloud Music, AMLL/TTML and YRC word-by-word lyrics, shared listening, and audio caching.

* [MeT-Music_iOS](https://github.com/MeTerminator/MeT-Music_iOS)

    * 基于 SwiftUI 的 iPhone、iPad 与原生 macOS 客户端，支持 QQ 音乐和网易云音乐、Apple Music 风格逐字歌词、后台播放、锁屏控制、一起听与本地缓存，并为 iPad 和 Mac 提供双栏播放器布局。
    * A native SwiftUI client for iPhone, iPad, and macOS with QQ Music and NetEase Cloud Music, Apple Music-style word-by-word lyrics, background playback, lock-screen controls, shared listening, and local caching, plus a two-column player layout for iPad and Mac.
